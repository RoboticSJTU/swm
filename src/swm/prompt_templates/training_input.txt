Given an instruction, an initial scene image, and a robot configuration, generate a task-relevant symbolic world model as a valid PDDL domain and problem for robotic planning.

Input
- Instruction: {instruction}
- Initial scene image: attached
- Robot configuration: {robot_configuration}

Rules
1. Symbolic representation
- Use untyped PDDL with unary category predicates.
- Declare every used predicate in :predicates, with consistent names, argument counts, and argument order.
2. Objects and initial state
- Ground task-relevant object instances, hands, and source/target areas in the scene. Encode their categories, current states (e.g., open/closed, is_on/is_off), and hand occupancy in :init from the image and explicit scene descriptions.
- Encode spatial relations according to each predicate's meaning, without substituting indirect supports or containers for immediate ones. Do not infer initial facts from desired outcomes.
3. Task requirements
- Encode the instruction's required final conditions in :goal, grounded in the correct objects and target areas.
- Preserve required operations, methods, and ordering in the action model.
4. Operators and causal constraints
- Include all operators needed for a valid plan from :init to :goal, including preparation and intermediate operations required by the scene, task, and robot configuration.
- Model each operator as a robot operation with necessary preconditions and direct effects on states, locations, and hand occupancy. Preserve causal dependencies so that required operations cannot be bypassed.

Output only in the following format, without explanations or Markdown fences:
<domain>
[complete PDDL domain]
</domain>
<problem>
[complete PDDL problem]
</problem>
