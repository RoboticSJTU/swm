Given an initial scene image, an instruction, and a robot configuration, generate the causally sufficient, task-relevant symbolic world model as a valid PDDL domain and problem for robotic task planning.

Input
- Initial scene image: attached
- Instruction: {instruction}
- Robot configuration: {robot_configuration}

PDDL requirements
1. Symbolic representation
- Use untyped PDDL with mandatory unary category predicates: every action parameter must have its category predicate in :precondition, and every object in :init.
- Declare all used predicates in :predicates with consistent names, arities, and meanings.
2. Operators and state transitions
- Define all causally necessary operations, including preparatory and intermediate steps, with correct parameters, preconditions, and effects.
- Respect task instructions, robot configuration, and physical constraints. Maintain consistent locations, mutually exclusive states, and hand occupancy through accurate add/delete effects.
- Ensure task completion from the initial state without unintended shortcuts.
3. Problem definition
- Ground task-relevant objects and encode only evidence-supported initial facts, including categories, direct spatial relations, states, and hand occupancy. Never infer transitive relations or initial facts from goals.
- Specify all required final conditions in :goal, grounded in the correct objects, locations, and states.

Output only in the following format, without explanations or Markdown fences:
<domain>
[complete PDDL domain]
</domain>
<problem>
[complete PDDL problem]
</problem>
