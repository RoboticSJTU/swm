Given an initial scene image, an instruction, and a robot configuration, generate the causally sufficient, task-relevant symbolic world model as a valid PDDL domain and problem for robotic task planning.

Input
- Initial scene image: attached
- Instruction: {instruction}
- Robot configuration: {robot_configuration}

PDDL requirements
1. Symbolic representation
- Use untyped PDDL with unary category predicates. Represent task-relevant entities, states, and relations.
- Declare every used predicate in `:predicates`, maintaining consistent names, argument counts, and roles across both files.
2. Operators and state transitions
- Identify the operations, preparatory steps, and intermediate state transitions needed to accomplish the task from the initial scene and robot configuration. Model genuine causal dependencies.
- Define each operator as a complete, executable operation event, with correctly bound participants, necessary preconditions and effects. Respect the instruction's required operations, execution methods, and physical constraints.
- Accurately add and delete facts according to each operation's effects, preserving unaffected facts. Maintain consistent object locations, mutually exclusive states, and hand occupancy across transitions.
- Ensure the operators enable all required task outcomes from the initial state without unintended shortcuts.
3. Problem Definition
- Ground task-relevant entities using the image, instruction, and robot configuration. Encode only evidence-supported initial facts, including category memberships, direct spatial relations, relevant states, and hand occupancy in `:init`.
- Encode only direct spatial relations, without inferring transitive relations (e.g., an apple on a plate on a table is not directly on the table). Do not infer initial facts from desired outcomes.
- Encode the instruction's required final conditions in `:goal`, grounded in the correct objects, target areas, and states.

Output only in the following format, without explanations or Markdown fences:
<domain>
[complete PDDL domain]
</domain>
<problem>
[complete PDDL problem]
</problem>
