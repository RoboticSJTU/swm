; Reuse predicates by meaning; extend only for necessary semantics with fixed argument roles and a defined lifecycle.
; Omit predicates unused by actions/goals and synonymous facts; prefer direct relations over bookkeeping.
; Functional categories are static unary init facts, separate from states and relations.
; Materials have containment relations and their own states; do not duplicate material states on containers. Split portions only for independently tracked locations, composition, or processing results.

; Static categories and bindings
(hand ?h)
(dispenses ?s ?m) ; s can supply m, independent of flow, containment, or portion availability.
; Unlimited supplies use dispenses without in(material, source) or artificial available flags.
(controls ?c ?d) ; c operates device d.

; Hands and tool grips: each hand has unit holding/pressing capacity.
(hand_free ?h) ; Neither holding an object nor sustaining a button press.
(holding ?h ?o)
(pressing ?h ?b) ; Sustained control occupies h until release; momentary activation does not.
(grip_free ?t) ; Active one-payload grip is free; required to put the tool down.
(gripping ?t ?o) ; Acquire: grip_free -> gripping; release reverses this. Hand keeps holding tool.

; Spatial relations: default to coarse on/in; retain details needed for execution/results.
; Use relative placement only without a specified concrete spot. Omit incidental layout and transient alignment/tilt/reset internal to an operation.
; For stacking/nesting, omit stacked_on, surface roots, and propagated region membership.
(on ?o ?s) ; Direct support without a fine-grained position.
(in ?o ?c) ; Direct containment/nesting only; no transitive facts or implied closure.
(inserted ?o ?s) ; Insertion, distinct from support/containment.
(at ?o ?p) ; Only for instruction-required fine-grained surface positions: declare (position ?p) and static (part_of ?p ?s). Replaces on for that placement.

; Contents, upper loads, and opening access
(empty ?o) ; No direct in contents of any modeled kind.
(filled ?o) ; Required fill level reached, not just nonempty.
(clear ?o) ; No hand holds o and no direct upper load exists. Nested stack members count; ordinary contents do not. Maintain on pickup, release, and load changes.
(uncovered ?o) ; No opening occluder; use only for required opening access, never pure stacking/nesting.
